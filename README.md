# UNRP

A Minecraft roleplay mod inspired by unOrdinary. Active development is in [unrp-forge](unrp-forge/), for Minecraft 1.20.1 and Forge. [unrp](unrp/) contains the earlier Fabric prototype.

Start with the [Forge README](unrp-forge/README.md). The [file map](<unrp-forge/docs/where is what.md>) points to gameplay, textures, buildings and configuration. [Ability development](unrp-forge/docs/ABILITY_DEVELOPMENT.md) explains how moves connect to the server.

The maintained interface, data and documentation are in English. Existing storage IDs and names of people remain stable so language changes do not invalidate saved characters.
